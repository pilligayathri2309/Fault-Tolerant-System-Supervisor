How to demonstrate

  1. The dashboard requests live health data from API Gateway.
  2. Lambda checks registered load-balancer targets and identifies their Availability Zones.
  3. The dashboard refreshes automatically every 60 seconds.
  4. Use the AWS EC2 console to terminate one test instance at a time, then observe the target health and Auto Scaling replacement.
Monitoring note: The indicators show application-target health in each Availability Zone, not proof of an AWS-wide Availability Zone outage. A zone with no registered target is shown as UNKNOWN. No physical hardware is required.
